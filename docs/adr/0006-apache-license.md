# 6. Apache-2.0 licence with Developer Certificate of Origin

Status: Accepted

Date: 2026-10-11

## Context

slack-rewind is an open-source tool designed for individuals and teams catching up on workplace chat. A clear, business-friendly open source licence is needed to encourage adoption while granting patent rights and clarifying contributions.

## Decision

The project is licensed under Apache-2.0. Contributions follow the Developer Certificate of Origin (DCO) using `git commit -s`. There is no Contributor License Agreement (CLA) or monetisation plan.

## Consequences

- The codebase is free for personal, team, and corporate use forever.
- Downstream users and contributors receive an explicit patent grant.
- All commits require sign-off (`Signed-off-by`).
